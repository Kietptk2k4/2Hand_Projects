GHN Webhook Demo

Dev-only: POST giả callback GHN tới commerce qua ngrok. Máy khác mở file này, dán URL ngrok + mã vận đơn, bấm status.

Không cần kèm path. Tool sẽ gọi /commerce/api/v1/shipments/webhooks/ghn.

Map: ready_to_pick→READY_TO_SHIP · picking→PICKING_UP · delivering→SHIPPED · delivered→DELIVERED · cancel→CANCELLED · return→RETURNED

Tôn trọng transition policy: ví dụ PENDING → delivering rồi mới delivered. Không nhảy thẳng delivered nếu shipment còn PENDING (Commerce sẽ ignore).
